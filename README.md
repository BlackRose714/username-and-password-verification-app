# username-and-password-verification-app
This is a username and password validation application written in Python.
First, the program takes a username and password input from the user using the input() function.

Then, an if condition is used to check whether the entered username and password meet the required conditions.
If all conditions are satisfied, the program prints "Valid username and password." to the screen and terminates.

If the conditions are not met, the program prints "Invalid username or password, please enter again."
Thanks to the while True loop, the program restarts and asks the user to enter the username and password again.
